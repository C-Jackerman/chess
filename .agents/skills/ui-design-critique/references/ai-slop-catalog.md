# AI-Slop Detection & High-Craft Replacement Catalog

This catalog defines the 16 most common "AI-generated UI" anti-patterns (synthesized from `Nutlope/hallmark` and `pbakaus/impeccable`) and prescribes exact architectural replacements.

| # | AI-Slop Pattern | Why It Weakens the Design | High-Craft Replacement |
| :--- | :--- | :--- | :--- |
| **1** | **Arbitrary Purple / Magenta / Cyan Gradients** (`#a855f7`, `#ec4899`, `#3b82f6` everywhere) | Screams "default LLM template", fatigues the eye, and destroys domain authenticity. | Use a restrained architectural neutral base (`#0c0d10`–`#1c1f24`) with **one** domain-appropriate accent (e.g., championship brass/gold `#d4a853` or tournament emerald `#10b981`). |
| **2** | **Every Section Is a Card (Card-in-Card Bloat)** | 3–4 levels of nested rounded borders create visual claustrophobia and waste 25%+ of horizontal space on padding/borders. | Maximum 2 container levels. Group internal items using whitespace (`--space-md`), subtle `1px` hairlines (`border-bottom`), or flush list rows. |
| **3** | **Excessive Glassmorphism & Neon Box-Shadows** (`backdrop-filter: blur(20px)` + `0 0 28px rgba(139,92,246,0.4)`) | Creates muddy contrast, halation around text, and cheap "gaming sticker" aesthetics. | Use crisp opaque/96% matte surfaces (`#131519`) with `1px solid rgba(255,255,255,0.07)` hairlines and grounded elevation shadows (`0 12px 32px rgba(0,0,0,0.45)`). |
| **4** | **Upscaled / Cropped Raster Assets with Compression Artifacts** | Scaling a low-res JPEG/PNG crop onto a Retina canvas looks blurry, plastic, and pasted-on. | Use resolution-independent, multi-layered vector SVG artwork with physical material stops, crisp specular bevels, and grounded drop shadows. |
| **5** | **Emoji / Unicode Characters Used as UI Icons** (`🏠`, `⚙️`, `🔥`, `♟️`) | Renders inconsistently across OSes, breaks monochrome/accent hierarchy, and looks amateurish. | Use a single unified vector SVG icon library (Lucide/Tabler geometry, `1.5px–2px` stroke, optical `24x24` grid). |
| **6** | **Competing Focal Points (Noisy Promo Banners & Fake Badges)** | Fake XP bars, unread notification dots on static buttons, and giant promo banners steal attention from the primary workspace. | Apply the `impeccable quieter` pass: remove fake gamification noise and keep secondary showcases compact, editorial, and subordinate to the main canvas. |
| **7** | **Redundant 3-Line Selector Boxes** (Icon + Caption + Value + Sub-caption + Chevron in a 2×2 grid) | Turns 4 simple match settings into 16 lines of competing text. | Use clean, scannable 2-line or inline segmented controls (`Label` + `Value`) with high contrast on the selected option. |
| **8** | **Proportional Numbers in Clocks & Tables** | Digital clocks and ELO ratings jitter horizontally every second as digits change width. | Always enforce `font-family: var(--font-mono)` and `font-variant-numeric: tabular-nums` on all timers, scores, coordinates, and move tables. |
| **9** | **Inconsistent Border Radii** (Mixing `6px`, `9px`, `10px`, `11px`, `12px`, `13px`, `14px`, `16px`, `18px`) | Makes the interface feel assembled by 10 different people without a token system. | Restrict corner radii to 3 semantic tokens: `--radius-sm: 6px` (controls/cells), `--radius-md: 8px` (cards/inputs), `--radius-lg: 12px` (panels/modals). |
| **10** | **Board / Canvas Coordinates Colliding with Content** | Placing high-opacity labels on top of piece bases creates visual clutter. | Keep coordinate labels subtle (`10px`, `font-weight: 600`, low-glare contrast) tucked cleanly into corner gutters (`4px` inset) or a dedicated `18px` frame rim. |
| **11** | **Unbounded Animation / Bouncy Keyframes** | Bouncing icons and glowing pulses distract players during concentration-heavy tasks. | Limit transitions to `140ms–200ms cubic-bezier(0.25, 1, 0.5, 1)` communicating direct hover/active causality. |
| **12** | **Missing `:focus-visible` Keyboard States** | Removing `outline` without providing a `:focus-visible` ring breaks keyboard navigation. | Define `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px; }` globally. |
